# Ainteractivo-web

Sitio web oficial de **Aprendizaje Interactivo SAS**, disenado para fortalecer el posicionamiento digital de la compania, comunicar su propuesta de valor y facilitar la conversion de interesados en oportunidades comerciales y academicas.

## Vision corporativa del proyecto

`Ainteractivo-web` es una plataforma web institucional desarrollada como activo estrategico de marca. Su objetivo es consolidar una presencia digital confiable, moderna y orientada a resultados para Aprendizaje Interactivo SAS.

La pagina esta orientada a:

- Presentar con claridad la identidad, trayectoria y diferenciales de Aprendizaje Interactivo SAS.
- Exponer la oferta de servicios con enfoque comercial y lenguaje de negocio.
- Aumentar la confianza de clientes potenciales, aliados e instituciones educativas.
- Impulsar la captacion de leads mediante canales de contacto directos y efectivos.
- Garantizar una experiencia profesional, rapida y responsive en todo tipo de dispositivo.

Este repositorio contiene el frontend institucional del sitio y forma parte de la estrategia digital de la organizacion.

## Propuesta de valor

La pagina web de Aprendizaje Interactivo SAS se concibe como una vitrina corporativa de alto impacto, enfocada en:

- **Credibilidad de marca:** presencia visual coherente con estandares corporativos.
- **Comunicacion efectiva:** mensajes claros sobre servicios, beneficios y alcance.
- **Generacion de oportunidades:** contacto simplificado para potenciales clientes y aliados.
- **Escalabilidad digital:** base tecnica ligera, mantenible y preparada para evolucion.

## Tecnologias principales

- [Astro v4](https://astro.build/) para construccion de sitio estatico.
- HTML, CSS y JavaScript para la capa de interfaz.
- GSAP y recursos visuales externos para animaciones e iconografia.
- Formspree para recepcion de mensajes del formulario de contacto.

## Ejecucion local

1. Instalar dependencias:

   ```bash
   npm install
   ```

2. Iniciar servidor de desarrollo:

   ```bash
   npm run dev
   ```

3. Abrir en navegador:

   [http://localhost:4321](http://localhost:4321)

## Scripts utiles

- `npm run dev`: levanta el entorno de desarrollo.
- `npm run build`: genera la version de produccion en `dist/`.
- `npm run preview`: previsualiza la build de produccion.
- `npm run check`: ejecuta validaciones de Astro.
